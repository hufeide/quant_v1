## 2. 公开接口连通性测试（实测结果）

回测与实盘的数据源可行性需要实测，本次结果如下：

| 接口 | 用途 | 实测结果 | 说明 |
|------|------|---------|------|
| `https://qt.gtimg.cn/` | 腾讯实时行情（快照主源之一） | **200 可达** | 可作为实盘快照源 |
| `https://hq.sinajs.cn/` | 新浪实时行情（备用源） | 403（需 Referer 头） | 需带 `Referer: https://finance.sina.com.cn` 才能访问 |
| `https://api.openalex.org/works` | 学术文献检索 | 200 可达 | 本报告文献来源 |
| `https://api.semanticscholar.org/graph/v1/paper/search` | 学术文献检索 | 429（限流） | 备选，需控制请求频率 |
| `https://arxiv.org/abs/<id>` | arXiv 页面 | 404（单条 URL 探测） | 批量检索接口 robots 受限，改用 OpenAlex |
| `https://pypi.org` | 依赖安装 | 200 可达 | akshare / backtrader 可安装 |
